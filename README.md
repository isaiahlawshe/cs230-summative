# Campus Club Event Finder

A client-side campus events interface built with HTML, CSS, and JavaScript.

## Features
- Search event names, organizations, categories, and locations
- Filter by category, start date, and free events
- Sort by date, name, price, or RSVP count
- Summary statistics update to reflect the currently visible events
- Responsive layout and different visual styles for free and paid events

## Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## Files
- `index.html`: semantic page structure and form controls
- `styles.css`: responsive layout and presentation
- `script.js`: sample event data, filtering, sorting, rendering, and aggregation
- `answers.txt`: dataset field justification
